# 📱 RITH RATHA — Social Link & Official Contact Dashboard

A responsive web-based **Official Contact Dashboard** built for **RITH RATHA** to centralize social media channels, contact access, and QR code sharing in one place.

🔗 **Live Demo:** [https://rithratha.github.io/mycontact/](https://rithratha.github.io/mycontact/)

---

## ✨ Key Features
- **Official Contact Hub:** Displays profile identity, QR code access, and direct contact actions.
- **Social Channels Grid:** Quick links to Telegram, YouTube, Facebook, and TikTok.
- **Responsive Dark UI:** Clean layout designed for smooth viewing on both mobile and desktop screens.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** GitHub Pages
